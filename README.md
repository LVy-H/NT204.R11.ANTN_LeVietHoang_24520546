# PCP — Packet Capture & Parser for an IDS

Module thu thập và phân tích gói tin cho hệ thống IDS/IPS (Bài tập 1).

> Trạng thái: đang phát triển. Nội dung đầy đủ (schema output, hướng dẫn chạy,
> kết quả test case, khai báo sử dụng AI) sẽ được bổ sung khi hoàn thành.

## Cài đặt

```bash
uv sync
```

## Chạy

```bash
uv run main.py --interface eth0
uv run main.py --pcap test.pcap
```
