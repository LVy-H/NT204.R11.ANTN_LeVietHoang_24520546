# Decoder Implementation Plan (plan 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `ids/decoder/`, which decodes characters, URLs/forms, HTML entities and MIME bodies. Results go into `record.decoded` and problems into `record.issues`, without touching any raw field.

**Architecture:** Four pure helpers: `text.py` (bytes → text, with charset fallback and an invalid-byte census), `url.py` (single-pass percent decoding), `html.py` (counted entity replacement) and `mime.py` (stdlib `email` structure plus hand-written transfer decoding). `stage.py` routes `PacketEvent`/`MessageEvent` records to them. `DecoderStage` comes first in `build_stages()` and is configured by `--max-decoded-bytes`.

**Tech Stack:** Python ≥ 3.10 stdlib only (`codecs`, `re`, `html`, `base64`, `quopri`, `email`), pytest, ruff, uv.

**Spec:** `docs/specs/2026-10-10-decoder-preprocessor-flow-tracker.md` (§7, §10.4, §11.3 T01–T04) and the shared contract `docs/plans/2026-10-10-interfaces.md` (§2 issues, §3.3 decoded model, §8 runner/stage, §9 CLI, §10 stage APIs). Executors read both.

## Global Constraints

- `requires-python >= 3.10`. No 3.11+ APIs (`tomllib`, `binascii` `strict_mode`, `datetime.UTC`, `typing.Self`). Base64 validation is done by hand.
- No new runtime dependency; stdlib only. Scapy is not used by this plan.
- Every module starts with `from __future__ import annotations` (an optional module docstring may come before it).
- Use the contract names, types and signatures verbatim: `decode_text(data: bytes, declared_charset: str | None = None, *, max_bytes: int = 1_048_576) -> DecodedText`, `decode_uri(uri: str) -> DecodedUri`, `decode_form(data: bytes) -> DecodedForm`, `decode_entities(text: str) -> tuple[str, int]`, `decode_message(data: bytes, issues: Issues, *, max_bytes: int = 1_048_576) -> DecodedMime`, `DecoderConfig(max_decoded_bytes: int = 1_048_576)`, `DecoderStage(config: DecoderConfig | None = None)` with `name = "decoder"`.
- The decoder never mutates raw fields (`application.message.*`, `payload.*`, `MessageEvent.data`). It writes only `record.decoded` and appends to `record.issues` through `Issues("decoder", record.issues)`.
- Decoder issue codes are exactly `invalid_escape`, `invalid_charset_bytes`, `invalid_base64`, `invalid_quoted_printable`, `unsupported_encoding`, `decoded_truncated`, all with stage `decoder`.
- `DecodeStatus` values: `not_applicable`, `unchanged`, `decoded`, `partial`, `failed`. Aggregates use `worst_status` from `ids.model`.
- `--max-decoded-bytes` defaults to `1048576`, uses the `non_negative_int` argparse type from plan 1c, and a negative value exits with 2.
- Runner stage order is `[DecoderStage, PreprocessorStage, FlowTrackerStage]`. Plan 2 leaves `build_stages` returning `[DecoderStage(DecoderConfig(max_decoded_bytes=args.max_decoded_bytes))]`.
- Lint: `uv run ruff check . && uv run ruff format --check .` (line length 100; rules E,F,W,I,UP,B,C4,SIM,RUF; SIM108, SIM115, BLE001 ignored).
- Green rule: every commit keeps `uv run pytest -q` green, and each task is exactly one commit. Commit messages are lower-case conventional (`feat: …`).
- Plan 2 starts after plan 1c's last commit. `ids/model`, `ids/issues.py`, `ids/payload.py` (`sha256_hex`, `looks_binary`), `ids/parsers` (`PacketParser`), `ids/pipeline.py` (`Runner`, `Stage`, `Emit`), `ids/sink.py` (`JsonlSink`), `ids/stats.py` (`Stats`), `ids/capture` (`EventsSource`) and `ids/cli.py` (`non_negative_int`, `build_stages` returning `[]`) all exist exactly as the contract describes.

## Decisions this plan fixes (the contract leaves them open)

| Topic | Decision |
|---|---|
| `DecodedText.status` | `unchanged` when the bytes are ASCII and the text equals them; `decoded` for any other strict decode; `partial` for the UTF-8 `replace` fallback. HTML entity replacement upgrades `unchanged` → `decoded` when `entity_count > 0`. |
| `invalid_byte_count` | Counts invalid **bytes** (`\xff\xfe` + cut `\xe2\x82` = 4). The text holds one U+FFFD per maximal invalid subsequence, identical to `errors="replace"`. It is `0` on success, with `first_invalid_offset` `None`. |
| Declared charset | The name is stripped and lowercased. A declared charset that fails (unknown name, non-text codec such as `rot13`, strict decode error, or a result with lone surrogates) falls through to strict UTF-8 and then to UTF-8 `replace`. The reported charset is the one that produced the text. |
| Cap | `max_bytes` limits the UTF-8 length of the returned text, cut on a character boundary. `truncated` is set but status is not changed; callers add `decoded_truncated`. |
| `DecodedUri.path` | The percent-decoded path component. Absolute-form `scheme://authority` is dropped (`""` when there is no path). Origin-form is everything before `?`. |
| `DecodedUri.text` / `query` | `text` = decoded head + `?` + decoded query (with `+` → space); `query` is `None` when the target has no `?`. Status is `decoded` when `text != uri`, `unchanged` otherwise, and `partial` on any invalid escape or invalid UTF-8. |
| URI bytes | The parser stores the target latin-1 decoded, so `uri.encode("latin-1")` restores the wire bytes. A loaded `uri` with code points above U+00FF is taken as UTF-8 (`surrogatepass`). |
| Params | Split on `&` before decoding; empty segments are dropped; `name` without `=` gives value `""`; duplicates and order are kept. |
| URI/form issues | `invalid_escape` when the raw input has a `%` not followed by two hex digits, otherwise `invalid_charset_bytes` when status is `partial`. Context `{"field": "uri"}` or `{"field": "form"}`. When both problems occur, only `invalid_escape` is reported. |
| HTTP body | Decoded when `body.length > 0`. Bytes = `payload.data[offset:offset+length]`. Decoded as text when the media type is `text/*`, `application/json`, `application/xml`, `application/javascript`, `application/x-www-form-urlencoded`, or `*+json`/`*+xml`, or when the header is absent and `looks_binary` is false. A `Content-Encoding` other than `identity` → no body text (spec §3 non-goal). Otherwise `decoded.body = None`. Entities are decoded only for `text/html`, `text/xml`, `application/xhtml+xml`, `text/plain`, or an absent Content-Type. |
| Missing body bytes | Fewer bytes than `body.length` (payload cap, or `payload.data is None` on loaded events) → body `partial` + `decoded_truncated` with context `{"field": "body", "expected", "available"}`. `HttpBody.truncated` (Content-Length > captured) is already reported by the parser as `truncated_body` and is not reported again. |
| `DecodedHttp` | Set for every `HttpMessage` packet. `uri` only for `kind == "request"` with a non-`None` uri. `status` = worst of the present uri/form/body, or `not_applicable` when none are present. |
| SMTP packets | Any `SmtpSession` message whose payload header area (bytes before the first blank line, or the whole payload) has a line starting `MIME-Version:`, `Content-Type:` or `Content-Transfer-Encoding:` (case-insensitive) gets `DecodedMime`. `payload.data_truncated` → `decoded_truncated` (field `payload`) and the status is raised to at least `partial`. `MessageEvent` → always `decode_message(data or b"")`. |
| MIME parts | Only leaf parts, 0-based `index` in `walk()` order. `content_type` = `get_content_type()`. `transfer_encoding` is lowercased (or `None`). `charset` = the charset used for text parts, or the declared one for others. `size`/`sha256` are those of the decoded bytes; for `failed` parts `size`/`sha256`/`text` are `None`. `truncated` is always a bool. The contract `MimePart` has no `issues` field, so part problems go to the record issues with `context["part"] = index`. |
| MIME headers | All six `MimeHeaders` fields use `decode_header` + `decode_text` per chunk, then are unfolded and stripped. A broken encoded word keeps the raw value and adds `invalid_base64` (`field` = header name lowercased). |
| Terminator | Only the trailing `.\r\n` of `\r\n.\r\n` is removed, so the last line keeps its CRLF. Any `..` at a line start becomes `.`. |
| QP validity | `=` must be followed by two hex digits (either case, as `binascii.a2b_qp` accepts), a line break, or the end of the data. Anything else (including `= ` before a line break, which `a2b_qp` keeps literally) is malformed. |

## Review Focus

1. **Declared escape codecs.** A body declared `charset=unicode_escape` or `utf-7` can decode to lone surrogates. These crash the UTF-8 JSONL sink (`UnicodeEncodeError`) far from the decoder. Expected: the declared charset is rejected and the UTF-8 path is used. Test: `test_escape_codec_that_would_yield_lone_surrogates_is_rejected` (Task 1).
2. **Binary or compressed HTTP bodies.** An `image/png` response, a gzip `Content-Encoding`, or an untyped binary body would turn into an `invalid_charset_bytes` issue on every packet, and the preprocessor would mark them partial. Expected: `decoded.body = None` and no issue. Tests: `test_binary_media_type_is_not_decoded_as_text`, `test_compressed_body_is_not_decoded_as_text`, `test_absent_content_type_binary_body_is_not_decoded` (Task 5).
3. **8-bit MIME content (SMTPUTF8 / 8BITMIME).** `Message.get_payload()` silently re-decodes 8-bit bodies with `errors="replace"`, and raw UTF-8 header bytes come back as `Header` objects. Expected: the body bytes stay byte-exact (correct sha256) and a raw UTF-8 `Subject` reads correctly. Tests: `test_eight_bit_utf8_body_is_decoded_byte_exact`, `test_raw_utf8_header_without_encoded_words_is_decoded` (Task 4).
4. **Second half of a split DATA body.** A later segment with plain body text, or a `Content-Type:` line only after a blank line, must not be MIME-decoded into a bogus single part. A segment that starts with a part header block is decoded. Tests: `test_smtp_payload_without_mime_header_block_is_not_decoded`, `test_smtp_segment_starting_with_a_part_header_block_is_decoded` (Task 5).
5. **Loaded events with no payload bytes.** A JSONL event whose `payload.data_b64` is absent but whose HTTP body declares a length has no bytes to decode. Expected: no crash, body `partial`, and `decoded_truncated` with expected/available counts. Test: `test_missing_payload_bytes_for_a_declared_body_is_partial` (Task 5). The related large-input case (64 KiB of invalid bytes counted in linear time) is pinned by `test_long_run_of_invalid_bytes_is_counted_per_byte` (Task 1).

Create `ids/decoder/text.py`. The strict decode stops at the first error. The loop then re-decodes only the valid run before that error and resumes after it, so each byte is decoded at most twice. This is linear, and the output is identical to `errors="replace"`.

```python
from __future__ import annotations

import codecs
import re

from ..model import DecodedText, DecodeStatus

_REPLACEMENT = "\ufffd"
_SURROGATE = re.compile("[\ud800-\udfff]")


def _declared(data: bytes, declared_charset: str | None) -> tuple[str, str] | None:
    """Strict decode with a charset Python knows; None when unknown, failing or unsafe.

    Escape codecs (unicode_escape, utf-7, ...) can yield lone surrogates, which no UTF-8
    writer accepts, so such a result counts as a failed decode."""
    if not declared_charset:
        return None
    name = declared_charset.strip().lower()
    if not name:
        return None
    try:
        text = data.decode(name)
    except (LookupError, ValueError):  # unknown / non-text codec, bad name, UnicodeError
        return None
    if not text.isascii() and _SURROGATE.search(text):
        return None
    return text, name


def _decode_utf8_replace(data: bytes) -> tuple[str, int, int | None]:
    """UTF-8 with errors="replace", plus invalid byte count and first invalid offset.

    Each strict decode stops at the next error and only the valid run before it is decoded
    again, so every byte is decoded at most twice."""
    view = memoryview(data)
    pieces: list[str] = []
    invalid = 0
    first: int | None = None
    pos = 0
    size = len(data)
    while pos < size:
        try:
            pieces.append(codecs.utf_8_decode(view[pos:], "strict", True)[0])
            break
        except UnicodeDecodeError as error:
            start = pos + error.start
            end = pos + error.end
            if start > pos:
                pieces.append(codecs.utf_8_decode(view[pos:start], "strict", True)[0])
            pieces.append(_REPLACEMENT)
            invalid += end - start
            if first is None:
                first = start
            pos = end
    return "".join(pieces), invalid, first


def _cap(text: str, max_bytes: int) -> tuple[str, bool]:
    if len(text) * 4 <= max_bytes:  # a code point is at most 4 UTF-8 bytes
        return text, False
    encoded = text.encode("utf-8")
    if len(encoded) <= max_bytes:
        return text, False
    return encoded[:max_bytes].decode("utf-8", "ignore"), True


def decode_text(
    data: bytes, declared_charset: str | None = None, *, max_bytes: int = 1_048_576
) -> DecodedText:
    """Bytes → text; never raises. `max_bytes` caps the UTF-8 length of the returned text."""
    invalid = 0
    first: int | None = None
    declared = _declared(data, declared_charset)
    if declared is not None:
        text, charset = declared
        # an ASCII-compatible codec reproduces ASCII input exactly; EBCDIC and friends do not
        same = data.isascii() and text == data.decode("ascii")
        status = DecodeStatus.UNCHANGED if same else DecodeStatus.DECODED
    else:
        try:
            text = data.decode("utf-8")
        except UnicodeDecodeError:
            text, invalid, first = _decode_utf8_replace(data)
            charset = "utf-8"
            status = DecodeStatus.PARTIAL
        else:
            if data.isascii():
                charset, status = "ascii", DecodeStatus.UNCHANGED
            else:
                charset, status = "utf-8", DecodeStatus.DECODED
    text, truncated = _cap(text, max_bytes)
    return DecodedText(
        text=text,
        charset=charset,
        status=status,
        invalid_byte_count=invalid,
        first_invalid_offset=first,
        truncated=truncated,
    )
```

- [ ] **Step 3: Write the implementation**

Create `ids/decoder/url.py`. The algorithm is one left-to-right scan with `bytes.find(b"%")`. A `%` followed by two hex digits emits that byte and skips three. Any other `%` (`%G1`, `%4` at the end, a trailing `%`) emits a literal `%`, sets the invalid flag and skips one byte, so the following characters are scanned normally. Decoded output is never re-scanned. In the query and in forms, `+` is replaced by a space on the raw bytes *before* percent decoding, which is safe because `+` cannot occur inside a `%XX` escape, so `%2B` still decodes to `+`. Pairs are split on `&` and `=` before decoding, so `%26` and `%3D` stay inside their value. `urllib.parse.unquote` is not used because it hides invalid escapes.

```python
from __future__ import annotations

import re

from ..model import DecodedForm, DecodedUri, DecodeStatus
from .text import decode_text

_HEX = frozenset(b"0123456789abcdefABCDEF")
_REMAINING_ESCAPE = re.compile(r"%[0-9A-Fa-f]{2}")
_SCHEME = re.compile(rb"[A-Za-z][A-Za-z0-9+.-]*://")


def percent_decode(raw: bytes) -> tuple[bytes, bool]:
    """One left-to-right pass: `%XX` → that byte; every other `%` is kept literally.

    Returns (decoded, had_invalid_escape). Output of one escape is never re-read, so
    `%2541` becomes `%41`, not `A`."""
    pos = raw.find(b"%")
    if pos < 0:
        return raw, False
    out = bytearray()
    invalid = False
    start = 0
    size = len(raw)
    while pos >= 0:
        out += raw[start:pos]
        if pos + 2 < size and raw[pos + 1] in _HEX and raw[pos + 2] in _HEX:
            out.append(int(raw[pos + 1 : pos + 3], 16))
            start = pos + 3
        else:
            out.append(0x25)  # "%"
            invalid = True
            start = pos + 1
        pos = raw.find(b"%", start)
    out += raw[start:]
    return bytes(out), invalid


def _component(raw: bytes, *, plus: bool) -> tuple[str, bool, bool]:
    """Decode one URI component → (text, changed, partial)."""
    changed = False
    if plus and b"+" in raw:
        raw = raw.replace(b"+", b" ")
        changed = True
    decoded, invalid = percent_decode(raw)
    if len(decoded) != len(raw):  # every valid escape shortens the data by two bytes
        changed = True
    text = decode_text(decoded)
    if text.status is DecodeStatus.DECODED:
        changed = True
    return text.text or "", changed, invalid or text.status is DecodeStatus.PARTIAL


def _pairs(raw: bytes) -> tuple[list[list[str]], bool, bool]:
    """`a=1&b=&c&a=2` → [["a","1"],["b",""],["c",""],["a","2"]]; empty segments dropped."""
    params: list[list[str]] = []
    changed = partial = False
    for segment in raw.split(b"&"):
        if not segment:
            continue
        name, _, value = segment.partition(b"=")
        name_text, name_changed, name_partial = _component(name, plus=True)
        value_text, value_changed, value_partial = _component(value, plus=True)
        params.append([name_text, value_text])
        changed = changed or name_changed or value_changed
        partial = partial or name_partial or value_partial
    return params, changed, partial


def _status(changed: bool, partial: bool) -> DecodeStatus:
    if partial:
        return DecodeStatus.PARTIAL
    return DecodeStatus.DECODED if changed else DecodeStatus.UNCHANGED


def _target_bytes(uri: str) -> bytes:
    # The parser stores the target latin-1 decoded, so latin-1 restores the wire bytes.
    # Loaded events may carry other code points; their UTF-8 form is the best guess.
    try:
        return uri.encode("latin-1")
    except UnicodeEncodeError:
        return uri.encode("utf-8", "surrogatepass")


def decode_uri(uri: str) -> DecodedUri:
    raw = _target_bytes(uri)
    head, mark, query = raw.partition(b"?")
    head_text, _, partial = _component(head, plus=False)
    scheme = _SCHEME.match(head)
    if scheme is None:
        path = head_text
    else:  # absolute-form: drop scheme://authority
        slash = head.find(b"/", scheme.end())
        path = _component(head[slash:], plus=False)[0] if slash >= 0 else ""
    text = head_text
    query_text: str | None = None
    params: list[list[str]] = []
    if mark:
        query_text, _, query_partial = _component(query, plus=True)
        params = _pairs(query)[0]
        text = f"{head_text}?{query_text}"
        partial = partial or query_partial
    return DecodedUri(
        text=text,
        path=path,
        query=query_text,
        params=params,
        status=_status(text != uri, partial),
        double_encoded=_REMAINING_ESCAPE.search(text) is not None,
    )


def decode_form(data: bytes) -> DecodedForm:
    params, changed, partial = _pairs(data)
    return DecodedForm(params=params, status=_status(changed, partial))
```

- [ ] **Step 3: Write the implementation**

Create `ids/decoder/html.py`. The regex is the same character-reference grammar that `html.unescape` scans with. Matches do not overlap and `unescape` replaces each one independently, so unescaping each match equals unescaping the whole string. A match whose unescape returns itself (`&bogus;`) is an unknown entity and is not counted. `&#;` and a bare `&` do not match the grammar at all.

```python
from __future__ import annotations

import html
import re

# Same reference syntax html.unescape scans for, so per-match unescaping equals unescaping
# the whole string; a match whose unescape is itself is an unknown entity.
_REFERENCE = re.compile(r"&(#[0-9]+;?|#[xX][0-9a-fA-F]+;?|[^\t\n\f <&#;]{1,32};?)")


def decode_entities(text: str) -> tuple[str, int]:
    """Replace HTML character references; returns (text, number of references replaced)."""
    if "&" not in text:
        return text, 0
    count = 0

    def replace(match: re.Match[str]) -> str:
        nonlocal count
        reference = match.group(0)
        value = html.unescape(reference)
        if value != reference:
            count += 1
        return value

    return _REFERENCE.sub(replace, text), count
```

- `BytesParser(policy=compat32)` stores each leaf body as ASCII text with 8-bit bytes surrogate-escaped. `get_payload()` re-decodes 8-bit bodies with `errors="replace"`, and `get_payload(decode=True)` applies its own lenient transfer decoding. `_raw_body` therefore reads the stored `_payload` and re-encodes it with `surrogateescape`, which gives back the exact wire bytes.
- Base64: delete whitespace with `bytes.translate`. The first byte outside `[A-Za-z0-9+/=]` ends the valid region. Padding is valid only as `==` after 2 or `=` after 3 characters of the final quantum, at the very end. On any problem, the whole quanta before the first `=` or bad byte are decoded with `b64decode(validate=True)`. A trailing 2- or 3-character quantum is padded and decoded too, so `WGk` still yields `Xi`. Status is then `partial` with an `invalid_base64` issue.
- Quoted-printable: `quopri.decodestring` (which calls `binascii.a2b_qp`) keeps malformed `=` sequences literally. `_QP_MALFORMED` counts every `=` that is not followed by two hex digits, a line break, or the end of the data.
- Header values are unfolded before `decode_header`. Unencoded chunks come back as ASCII bytes with charset `None`, because a `str` value from `compat32` is always ASCII (8-bit headers come back as `Header` objects with charset `unknown-8bit`, which `decode_text` treats as unknown → UTF-8).

```python
from __future__ import annotations

import base64
import quopri
import re
from email import policy
from email.errors import HeaderParseError
from email.header import decode_header
from email.message import Message
from email.parser import BytesParser

from ..issues import Issues
from ..model import DecodedMime, DecodeStatus, MimeHeaders, MimePart, worst_status
from ..payload import sha256_hex
from .text import decode_text

_PARSER = BytesParser(policy=policy.compat32)
_MIME_HEADER = re.compile(
    rb"^(?:mime-version|content-type|content-transfer-encoding)[ \t]*:",
    re.IGNORECASE | re.MULTILINE,
)
_DOT_STUFFED = re.compile(rb"^\.\.", re.MULTILINE)
_FOLD = re.compile(r"\r?\n(?=[ \t])")
_B64_WHITESPACE = b" \t\r\n\x0b\x0c"
_B64_OUTSIDE_ALPHABET = re.compile(rb"[^A-Za-z0-9+/=]")
_QP_MALFORMED = re.compile(rb"=(?![0-9A-Fa-f]{2}|\r?\n|\Z)")
_UNCHANGED_ENCODINGS = frozenset({"7bit", "8bit", "binary"})


def has_mime_headers(data: bytes) -> bool:
    """True when the header area (up to the first blank line) has a MIME header line."""
    end = data.find(b"\r\n\r\n")
    if end < 0:
        end = data.find(b"\n\n")
    return _MIME_HEADER.search(data, 0, end if end >= 0 else len(data)) is not None


def unstuff(data: bytes) -> bytes:
    """Drop the SMTP end-of-data line and undo dot-stuffing (RFC 5321 §4.5.2)."""
    if data.endswith(b"\r\n.\r\n") or data == b".\r\n":
        data = data[:-3]
    elif data.endswith(b"\n.\n") or data == b".\n":
        data = data[:-2]
    if data.startswith(b"..") or b"\n.." in data:
        data = _DOT_STUFFED.sub(b".", data)
    return data


def _decode_base64(raw: bytes) -> tuple[bytes, str | None]:
    """Strict base64 → (bytes, problem). With a problem, only the valid prefix is decoded."""
    compact = raw.translate(None, _B64_WHITESPACE)
    bad = _B64_OUTSIDE_ALPHABET.search(compact)
    end = bad.start() if bad is not None else len(compact)
    pad = compact.find(b"=", 0, end)
    stop = end if pad < 0 else pad
    rest = stop % 4
    problem: str | None = None
    if bad is not None:
        problem = f"byte 0x{compact[end]:02x} at offset {end} is outside the base64 alphabet"
    elif pad >= 0:
        if rest < 2 or compact[pad:] != b"=" * (4 - rest):
            problem = "invalid base64 padding"
    elif rest == 1:
        problem = "dangling base64 character"
    elif rest:
        problem = "missing base64 padding"
    if problem is None:
        return base64.b64decode(compact, validate=True), None
    whole = stop - rest
    decoded = base64.b64decode(compact[:whole], validate=True)
    if rest >= 2:  # a final 2- or 3-character quantum still carries whole bytes
        decoded += base64.b64decode(compact[whole:stop] + b"=" * (4 - rest), validate=True)
    return decoded, problem


def _decode_quoted_printable(raw: bytes) -> tuple[bytes, int, int | None]:
    """→ (bytes, malformed escape count, first malformed offset). Malformed `=` stay literal."""
    first: int | None = None
    count = 0
    if b"=" in raw:
        for match in _QP_MALFORMED.finditer(raw):
            if first is None:
                first = match.start()
            count += 1
    return quopri.decodestring(raw), count, first


def _header(message: Message, name: str, issues: Issues, max_bytes: int) -> str | None:
    """First `name` header, RFC 2047 words decoded, unfolded; None when absent."""
    value = message.get(name)
    field = name.lower()
    if value is None:
        return None
    if isinstance(value, str):  # compat32 hands out raw 8-bit headers as Header objects
        value = _FOLD.sub("", value)
    try:
        chunks = decode_header(value)
    except HeaderParseError as error:
        issues.add("invalid_base64", f"{name} header: {error}", field=field)
        return _FOLD.sub("", str(value)).strip()
    pieces: list[str] = []
    for chunk, charset in chunks:
        if isinstance(chunk, str):
            pieces.append(chunk)
        elif charset is None:  # text between encoded words; ASCII because value was str
            pieces.append(chunk.decode("latin-1"))
        else:
            decoded = decode_text(chunk, charset, max_bytes=max_bytes)
            if decoded.status is DecodeStatus.PARTIAL:
                issues.add(
                    "invalid_charset_bytes",
                    f"{name} header has bytes that are not valid {decoded.charset}",
                    field=field,
                    invalid_byte_count=decoded.invalid_byte_count,
                )
            if decoded.truncated:
                issues.add(
                    "decoded_truncated", f"{name} header cut at {max_bytes} bytes", field=field
                )
            pieces.append(decoded.text or "")
    return _FOLD.sub("", "".join(pieces)).strip()


def _transfer_decode(
    index: int, encoding: str | None, raw: bytes, issues: Issues
) -> tuple[bytes | None, DecodeStatus]:
    if encoding is None or encoding in _UNCHANGED_ENCODINGS:
        return raw, DecodeStatus.UNCHANGED
    if encoding == "base64":
        body, problem = _decode_base64(raw)
        if problem is None:
            return body, DecodeStatus.DECODED
        issues.add("invalid_base64", problem, part=index, decoded_bytes=len(body))
        return body, DecodeStatus.PARTIAL
    if encoding == "quoted-printable":
        body, malformed, first = _decode_quoted_printable(raw)
        if not malformed:
            return body, DecodeStatus.DECODED
        issues.add(
            "invalid_quoted_printable",
            f"{malformed} malformed quoted-printable escape(s) kept literally",
            part=index,
            count=malformed,
            first_offset=first,
        )
        return body, DecodeStatus.PARTIAL
    issues.add(
        "unsupported_encoding",
        f"Content-Transfer-Encoding {encoding!r} is not supported",
        part=index,
        encoding=encoding,
    )
    return None, DecodeStatus.FAILED


def _raw_body(part: Message) -> bytes:
    # BytesParser stores a leaf body as ASCII text with 8-bit bytes surrogate-escaped.
    # get_payload() re-decodes such bodies with errors="replace" and get_payload(decode=True)
    # applies its own lenient transfer decoding, so the stored value is read directly.
    payload = part._payload
    if isinstance(payload, str):
        return payload.encode("ascii", "surrogateescape")
    return payload if isinstance(payload, bytes) else b""


def _part(index: int, part: Message, issues: Issues, max_bytes: int) -> MimePart:
    content_type = part.get_content_type()
    declared_charset = part.get_content_charset()
    header = part.get("Content-Transfer-Encoding")
    encoding = str(header).strip().lower() if header is not None else None
    raw = _raw_body(part)
    body, status = _transfer_decode(index, encoding, raw, issues)
    result = MimePart(
        index=index,
        content_type=content_type,
        charset=declared_charset,
        transfer_encoding=encoding,
        filename=part.get_filename(),
        status=status,
        truncated=False,
    )
    if body is None:
        return result
    result.size = len(body)
    result.sha256 = sha256_hex(body)
    if content_type.startswith("text/"):
        text = decode_text(body, declared_charset, max_bytes=max_bytes)
        result.text = text.text
        result.charset = text.charset
        result.truncated = text.truncated
        result.status = worst_status((status, text.status))
        if text.status is DecodeStatus.PARTIAL:
            issues.add(
                "invalid_charset_bytes",
                f"part {index} has bytes that are not valid {text.charset}",
                part=index,
                invalid_byte_count=text.invalid_byte_count,
                first_invalid_offset=text.first_invalid_offset,
            )
        if text.truncated:
            issues.add(
                "decoded_truncated", f"part {index} text cut at {max_bytes} bytes", part=index
            )
    return result


def decode_message(data: bytes, issues: Issues, *, max_bytes: int = 1_048_576) -> DecodedMime:
    """Decode an RFC 5322/MIME message carried in SMTP DATA; problems go to `issues`."""
    message = _PARSER.parsebytes(unstuff(data))
    headers = MimeHeaders(
        subject=_header(message, "Subject", issues, max_bytes),
        from_=_header(message, "From", issues, max_bytes),
        to=_header(message, "To", issues, max_bytes),
        cc=_header(message, "Cc", issues, max_bytes),
        date=_header(message, "Date", issues, max_bytes),
        message_id=_header(message, "Message-ID", issues, max_bytes),
    )
    parts = [
        _part(index, part, issues, max_bytes)
        for index, part in enumerate(p for p in message.walk() if not p.is_multipart())
    ]
    return DecodedMime(
        headers=headers, parts=parts, status=worst_status(part.status for part in parts)
    )
```

```python
from __future__ import annotations

import re
from dataclasses import dataclass
from typing import TYPE_CHECKING

from ..issues import Issues
from ..model import (
    DecodedHttp,
    DecodedText,
    DecodeStatus,
    HttpMessage,
    MessageEvent,
    PacketEvent,
    Payload,
    SmtpSession,
    worst_status,
)
from ..payload import looks_binary
from .html import decode_entities
from .mime import decode_message, has_mime_headers
from .text import decode_text
from .url import decode_form, decode_uri

if TYPE_CHECKING:
    from ..pipeline import Emit

FORM_TYPE = "application/x-www-form-urlencoded"
ENTITY_TYPES = frozenset({"text/html", "text/xml", "application/xhtml+xml", "text/plain"})
TEXT_TYPES = frozenset({FORM_TYPE, "application/json", "application/xml", "application/javascript"})
_CHARSET = re.compile(r';\s*charset\s*=\s*"?([^";\s]+)', re.IGNORECASE)
_INVALID_ESCAPE = re.compile(r"%(?![0-9A-Fa-f]{2})")
_INVALID_ESCAPE_BYTES = re.compile(rb"%(?![0-9A-Fa-f]{2})")


@dataclass(slots=True)
class DecoderConfig:
    max_decoded_bytes: int = 1_048_576


def _media_type(content_type: str | None) -> tuple[str | None, str | None]:
    """`text/html; charset="UTF-8"` → ("text/html", "UTF-8"); absent header → (None, None)."""
    if content_type is None:
        return None, None
    media = content_type.split(";", 1)[0].strip().lower() or None
    charset = _CHARSET.search(content_type)
    return media, charset.group(1) if charset else None


def _is_text(media: str) -> bool:
    return media.startswith("text/") or media in TEXT_TYPES or media.endswith(("+json", "+xml"))


def _report_escapes(
    issues: Issues, field: str, status: DecodeStatus | None, invalid_escape: bool
) -> None:
    if status is not DecodeStatus.PARTIAL:
        return
    if invalid_escape:
        issues.add(
            "invalid_escape", f"invalid percent escape kept literally in {field}", field=field
        )
    else:
        issues.add(
            "invalid_charset_bytes", f"{field} is not valid UTF-8 after decoding", field=field
        )


class DecoderStage:
    name = "decoder"

    def __init__(self, config: DecoderConfig | None = None) -> None:
        self.config = config if config is not None else DecoderConfig()

    def process(self, record: PacketEvent | MessageEvent, emit: Emit) -> None:
        issues = Issues(self.name, record.issues)
        limit = self.config.max_decoded_bytes
        if isinstance(record, MessageEvent):
            record.decoded = decode_message(record.data or b"", issues, max_bytes=limit)
            return
        message = record.application.message if record.application is not None else None
        if isinstance(message, HttpMessage):
            record.decoded = self._http(message, record.payload, issues)
        elif isinstance(message, SmtpSession):
            data = record.payload.data if record.payload is not None else None
            if data and has_mime_headers(data):
                decoded = decode_message(data, issues, max_bytes=limit)
                if record.payload.data_truncated:
                    issues.add(
                        "decoded_truncated",
                        "SMTP payload was cut at --max-payload-bytes before MIME decoding",
                        field="payload",
                    )
                    decoded.status = worst_status((decoded.status, DecodeStatus.PARTIAL))
                record.decoded = decoded

    def tick(self, now: float, emit: Emit) -> None:
        return None

    def flush(self, emit: Emit) -> None:
        return None

    def _http(self, message: HttpMessage, payload: Payload | None, issues: Issues) -> DecodedHttp:
        decoded = DecodedHttp()
        if message.kind == "request" and message.uri is not None:
            decoded.uri = decode_uri(message.uri)
            _report_escapes(
                issues, "uri", decoded.uri.status, _INVALID_ESCAPE.search(message.uri) is not None
            )
        body = message.body
        if body is not None and body.length:
            start = body.offset or 0
            data = payload.data if payload is not None else None
            raw = data[start : start + body.length] if data is not None else b""
            media, charset = _media_type(message.header("content-type"))
            if media == FORM_TYPE:
                decoded.form = decode_form(raw)
                _report_escapes(
                    issues,
                    "form",
                    decoded.form.status,
                    _INVALID_ESCAPE_BYTES.search(raw) is not None,
                )
            decoded.body = self._body(message, raw, body.length, media, charset, issues)
        decoded.status = worst_status(
            part.status for part in (decoded.uri, decoded.form, decoded.body) if part is not None
        )
        return decoded

    def _body(
        self,
        message: HttpMessage,
        raw: bytes,
        length: int,
        media: str | None,
        charset: str | None,
        issues: Issues,
    ) -> DecodedText | None:
        encoding = message.header("content-encoding")
        if encoding is not None and encoding.strip().lower() not in ("", "identity"):
            return None  # compressed bodies are not decoded (spec §3)
        if media is None:
            if looks_binary(raw):
                return None
        elif not _is_text(media):
            return None
        limit = self.config.max_decoded_bytes
        text = decode_text(raw, charset, max_bytes=limit)
        if text.status is DecodeStatus.PARTIAL:
            issues.add(
                "invalid_charset_bytes",
                f"HTTP body has bytes that are not valid {text.charset}",
                field="body",
                invalid_byte_count=text.invalid_byte_count,
                first_invalid_offset=text.first_invalid_offset,
            )
        if media is None or media in ENTITY_TYPES:
            text.text, text.entity_count = decode_entities(text.text or "")
            if text.entity_count and text.status is DecodeStatus.UNCHANGED:
                text.status = DecodeStatus.DECODED
        if text.truncated:
            issues.add("decoded_truncated", f"HTTP body text cut at {limit} bytes", field="body")
        if len(raw) < length:
            issues.add(
                "decoded_truncated",
                "HTTP body bytes are missing from the captured payload",
                field="body",
                expected=length,
                available=len(raw),
            )
            text.status = worst_status((text.status, DecodeStatus.PARTIAL))
        return text
```
